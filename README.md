# Coffee Roaster Auto Control

Embedded firmware for an **automatic coffee roasting machine** built on **STM32 + PlatformIO + Arduino framework**.

The system controls the roasting process including temperature monitoring, burner control, airflow control, and roasting data logging.

This project is designed to support **stable roast profiles**, real-time control, and future **AI-assisted tuning**.

---

# Hardware Platform

Microcontroller:

STM32F103RC

Development Environment:

PlatformIO  
Arduino Framework

Typical hardware setup:

- STM32F103 controller board
- Temperature sensor (thermocouple / RTD)
- Pressure sensor
- Gas burner control
- Fan / airflow control
- I2C DAC output
- RS485 Modbus sensors
- SD card for data logging
