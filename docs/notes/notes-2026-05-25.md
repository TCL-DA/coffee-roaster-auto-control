# Ghi chú phiên làm việc 2026-05-25

## Đã làm

1. Giảm RAM profile:
   - Hạ `PROFILE_MAX_SECONDS` còn `2100`, tương đương 35 phút.
   - Đổi các mảng phần trăm `sdAirflow`, `sdGas`, `sdDrum`, `sdVacuumSetFlag` sang `uint8_t`.
   - Giữ lại `sdTiRoast[]` để tránh rủi ro sai thời gian profile.

2. Chặn lỗi phần trăm âm hoặc quá 100:
   - Thêm `clampProfilePercent()`.
   - Clamp Air/Gas/Drum khi lưu CSV và khi đọc CSV/TXT profile.
   - Tránh lỗi số âm lưu vào `uint8_t` rồi nhảy thành `255`.

3. Giảm dùng `String` ở đường SD/profile:
   - Đổi tên file profile sang buffer `char` + `snprintf`.
   - Đổi parser TXT sang buffer cố định.
   - `include/Program.h` và `include/Define.h` không còn `String` active ở đường SD/profile chính.

4. Tắt debug mặc định:
   - `enDebug = 0`.

5. Thêm fail-safe Modbus tắt gas:
   - Thêm `MODBUS_GAS_CUTOFF_FAIL_LIMIT = 5`.
   - Theo dõi lỗi liên tiếp cho HMI, BT, ET, air inverter, drum inverter, IO relay, vacuum.
   - Khi lỗi kéo dài: ép `START_GAS_BTN_R = 0`, `burnerValue_R = 0`, `gasPC = 0`, `gasPercent = 0`, tắt relay gas, kéo DAC gas về 0.
   - Gọi `enforceModbusGasCutoff()` trước `analogOut()` và trước `controlIO()`.

## Build cuối ngày

Build thành công:

```text
RAM:   34,532 / 49,152 B = 70.3%
Flash: 93,492 / 262,144 B = 35.7%
```

Cảnh báo còn lại:

- `ADDREG` redefined từ `ModbusESP`.
- `boolean` deprecated từ Arduino/legacy project code.

## Việc nên làm tiếp

1. Rà fail-safe Modbus trên máy thật: rút thử từng thiết bị RS485 và xác nhận gas về OFF.
2. Làm log lỗi có mã, timestamp, BT/ET, gas/air/drum, relay, nguồn lệnh.
3. Rà toàn bộ đường ghi gas/air/drum từ HMI, PC, profile, auto để clamp `0..100`.
4. Chuẩn hóa encoding UTF-8 cho comment tiếng Việt đang lỗi font.
5. Thiết kế `AI/PC command contract`: PC/AI chỉ gửi setpoint, STM32 giữ quyền safety cuối cùng.
